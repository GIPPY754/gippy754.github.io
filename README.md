# Hybrid Quantum Lab

Academic group website for the Hybrid Quantum Lab, Institute of Quantum Science and Technology, School of Physics, Peking University.

Built with React, TypeScript, Vite and Tailwind CSS.

## Development

npm ci
npm run dev

## Build

npm run build

Website content is in src/content.ts; layout is in src/App.tsx. Deployment uses .github/workflows/deploy.yml. In repository Settings > Pages, select GitHub Actions.
